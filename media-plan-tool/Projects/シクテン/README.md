# シクテン

サンプルプロジェクト。brief.json の書き方と generate.py の動作確認用。

## ファイル構成

| ファイル | 用途 |
|---|---|
| `input/brief.json` | 入力（施策情報を記述） |
| `output/media_plan.xlsx` | 出力（generate.py が生成） |

## 入力の前提

| 項目 | 値 |
|---|---|
| 総予算 | 1.5 億円 |
| 施策期間 | 2025-07 ~ 2025-12 |
| 施策数 | 3（インフルエンサー 1 + 広告配信 1 + ギフティング 1） |

### ad_type の意味

| 値 | 意味 | 主な入力フィールド |
|---|---|---|
| `配信有` | インフルエンサー施策（二次利用あり） | follower_unit_price, avg_followers, imp_rate, fq |
| `配信無` | インフルエンサー施策（二次利用なし） | 同上 |
| `広告配信` | 広告配信のみ | cpm, fq |

### allocation（予算配分）の扱い

- 各施策の `allocation` は総予算に対する比率（0〜1）
- 全施策の合計が 1.0 を超えないようにする
- 本サンプルの合計: 0.027 + 0.02 + 0.004 = 0.051（残りは未割当）

## 実行

```bash
python src/generate.py シクテン
```

## 出力の確認観点

output/media_plan.xlsx を開いたら以下を確認する:

1. **行数** — tactics の数（3）と Excel のデータ行数が一致しているか
2. **合計行** — SUM 数式がデータ行の範囲を正しくカバーしているか
3. **総予算** — 合計行の I 列が 150,000,000 になっているか
4. **数式の維持** — 予算（I列）が `=$I$合計行*H行` の数式になっているか（値ベタ打ちでない）
5. **書式** — 通貨（¥）、パーセント（%）、カンマ区切りが template.xlsx と同じか
6. **空欄** — 広告配信行に J/K/L/M/N 列の値が入っていないこと（入っていたら不正）
